# 🎯 秋招工作台 · 分享包

一个**单文件 HTML 秋招工作台**（投递追踪 + 时间线 + 每日打卡 + 岗位匹配），任何人都能拥有自己的版本。数据存在本地浏览器，无需服务器。

## 目录说明

| 文件 | 用途 | 适合谁 |
|------|------|--------|
| `模板-秋招工作台.html` | 直接可用的工作台模板（双击打开，自己录入公司/数据） | 不想用 AI、想立刻上手的人 |
| `提示词-秋招工作台生成.md` | 一段提示词，发给任意 AI 生成**定制版**工作台（换行业/岗位/城市都行） | 会用 AI 的人 |
| `skill-秋招工作台生成器/` | WorkBuddy 技能，AI 按固定流程生成工作台 | 用 WorkBuddy 的人（效果最稳定） |

## 三种使用方式

### 方式 A：直接用模板（零门槛）
1. 双击打开 `模板-秋招工作台.html`
2. 顶部改标题里的【你的名字】【你的学校】等信息
3. 点「➕ 添加单位」录入你的目标公司
4. 每天在「备考中心」勾选打卡、写备注
5. 定期点「💾 保存数据」下载备份（重要！）

### 方式 B：发给 AI 定制（推荐给懂 AI 的同学）
1. 打开 `提示词-秋招工作台生成.md`
2. 把提示词复制给任意 AI（WorkBuddy/Claude/ChatGPT/DeepSeek 等）
3. 把【方括号】内容替换成自己的学校/岗位/城市/项目
4. 得到 HTML 保存为 `秋招工作台.html`，双击使用

### 方式 C：装 WorkBuddy 技能（效果最稳定）
1. 把 `skill-秋招工作台生成器/` 文件夹放到 `~/.workbuddy/skills/` 下
2. 打开 WorkBuddy，说「帮我生成一个秋招工作台」，AI 会先问你的信息，然后按固定规范生成
3. 不同 AI 生成结果一致，换人换岗位都通用

## 工作台功能一览

- 📋 **投递追踪**：投递表（9 种状态、筛选/搜索/分页/链接可编辑）+ 顶部「购入秋招表」「我的信息源」两张链接卡片（自填）
- ⏱ **秋招时间线**：6 个阶段（提前批→签约/春招）彩色卡片，内容由使用者自填
- 📝 **备战中心**：多张链接卡片（八股/简历/工具/面试，自填）+ 面试记录 + 每日打卡（今日进度圆环、每任务独立备注、自定义任务、周视图）
- 🎯 **岗位匹配**：10 项能力打分（可改）、实时匹配度、短板清单、历史记录
- 💾 **数据安全**：localStorage 持久化 + 导出/导入 JSON 备份 + 一键重置

## 小贴士

- **换电脑/丢数据**：定期点「💾 保存数据」，新环境点「📂 打开数据」导入即可
- **备注太长撑高行**：备注默认截断显示，点击展开
- **想改自己的模板样式**：用浏览器打开 HTML 后 Ctrl+F 搜索文字直接改
- **模板里的示例**：时间线/学习资源/岗位匹配项是嵌入式方向的示例内容，请按你自己的行业岗位替换；「简历模板」按钮和 GitHub 卡片的链接是占位（example.com），记得换成你自己的

## 📤 上传 GitHub 分享

本文件夹就是一个完整的 GitHub 仓库结构，直接推送即可：

```bash
git init
git add .
git commit -m "秋招工作台生成器：提示词 + 模板 + WorkBuddy skill"
git remote add origin https://github.com/你的账号/仓库名.git
git push -u origin main
```

仓库公开后，分享给对方只需一句话：

> 「把这个链接发给你的 AI：https://github.com/你的账号/仓库名
> 让它① 安装 `skill-秋招工作台生成器` 这个 skill，或者 ② 按 `提示词-秋招工作台生成.md` 给我生成一个秋招工作台」

对方用 **WorkBuddy / Claude Code / Codex 等 Agent 类 AI** 时，AI 会自动 clone 仓库、读 skill/提示词、生成工作台；用**网页版 ChatGPT/豆包**等纯对话 AI 的同学，请把提示词文件内容复制给它。
