# 秋招工作台生成器（autumn-recruitment-workbench）

为一个求职者生成**单文件 HTML 秋招工作台**（双击浏览器打开即用、无服务器、数据存 localStorage）。换任何人的学校/岗位/经历都能用，只需替换用户信息。

## 使用流程

### 第一步：收集用户信息（用 AskUserQuestion 或直接提问）
1. 学校 / 专业
2. 目标岗位（如：嵌入式软件工程师、前端开发、产品经理）
3. 意向城市（如：成都、重庆；可多个）
4. 求职届次（如：2027届）
5. 项目/亮点（1-3 个，用于时间线和打卡任务的内容定制）
6. 目标行业方向（影响时间线阶段的任务内容与岗位匹配的 10 项能力）

若用户直接给出信息则跳过提问，进入生成。

### 第二步：生成工作台 HTML（单文件）
输出一个完整 HTML 文件，必须包含以下 5 个部分：

#### 1. 📋 投递追踪 Tab
- 表格列：序号/单位名称/性质/城市/工作地点/秋招时间/网申链接/笔试/薪资/投递状态/备注/简历文件/操作
- 投递状态 9 种：未投递/已投递/测评中/面试中/已录用/已拒绝/未开启/链接失效/岗位不符
- 状态列用下拉框，onchange 直接保存到 localStorage
- 顶部筛选器：按城市、按性质、按状态、关键词搜索；分页（每页 20/50/100/全部）
- 网申链接：可点击跳转 + 每行 ✏️ 编辑按钮（行内输入框修改）
- 备注列：内容超 40 字符默认截断显示「…」，点击展开全文
- 顶部统计卡片：目标单位总数/已投递/面试测评中/已录用/未开启失效不符/意向城市数量
- 右上角按钮：➕ 添加单位（弹窗表单）/ 🗑 删除行
- 公司数据初始为空数组（用户自行添加）

#### 2. ⏱ 秋招时间线 Tab
- 顶部渐变横幅：标题「⏰ 202X届秋招关键时间线」+ 副标题（绿=活跃、红=关键截止、灰=已过）
- 6 个阶段卡片，4 列网格：提前批&实习转正 / 正式批网申高峰 / 笔试密集期 / 面试高峰 / 签约&谈薪 / 春招补录
- 每卡：emoji 标题 + 时间段 + 左侧彩边（绿/红/蓝交替）+ 具体事项列表
- 内容按用户目标行业/岗位定制（如嵌入式：华为机考 C/C++、RTOS、通信协议等）

#### 3. 📝 备考中心 Tab
- 学习资源卡片：8 张（八股文资料/力扣/牛客/刷题平台/简历模板/模拟面试等），可点击跳转，可自定义
- 每日打卡：
  - 顶部「今日打卡进度」卡片：SVG 圆环（绿→橙→红渐变按完成度填充）+ 中间百分比 + 阶段标签 + 鼓励语
  - 周切换 Tab（上周/本周/下周/下下周）
  - 每天一行卡片：4-5 个任务（可勾选、完成变绿+删除线、**每个任务独立备注输入框**、可「+ 添加自定义任务」行内输入）
  - 阶段自动判断：日期 ≤ 截止日显示「项目冲刺期（截至X）」，否则「全面备战期」

#### 4. 🎯 岗位匹配 Tab
- 10 项能力打分器（按用户岗位定制，嵌入式默认：学历/C语言/STM32/RTOS/通信协议/BSP驱动/Linux/硬件/英语/项目经历）
- 每项三档：满足(2分)/部分(1分)/不满足(0分)
- 实时算匹配度百分比 + 等级（高/中/偏低/低）+ 短板清单 + 保存历史可加载

#### 5. 数据管理
- 数据全部存 localStorage（key: resume_tracker_data / checkin_data / custom_tasks / task_notes / match_history）
- 右上角按钮：💾 保存数据（导出 JSON 备份下载）/ 📂 打开数据（导入恢复）/ 🔄 重置全部
- 版本合并逻辑：DATA_VERSION 常量 + getData() 里若 localStorage 版本低则合并（同名公司保留用户状态）

### 第三步：技术约束（必须遵守，保证稳定）
- 单 HTML 文件，**零外部依赖**（不引 CDN、不引字体、不引图片）
- **JS 一律用单引号字符串 + 加号拼接生成 HTML**；**禁止跨行字符串字面量**（`'<div>...` 跨行是语法错误）；每行一个字符串用 `+` 连接
- 模板字符串（反引号）只允许：`\`...\`` 正确闭合、且不在 JS 中互相嵌套
- 生成后必须用 Node 校验：`node --check script.js`（提取 <script> 内容后检查）
- 样式规范：body 浅灰背景 #f5f6fa；header 深灰渐变 #2d3436→#636e72、圆角 16px、居中卡片式、带阴影；Tab 为 pill 圆角（border-radius:999px、flex:1 等宽均分、激活蓝底）；卡片化布局（白底圆角 12px 阴影）
- 中文字符串直接用，文件 UTF-8 编码
- 转义：拼接进 HTML 的文本用 esc() 函数处理（& < > 转义）

### 第四步：校验清单（生成后逐项自查）
- [ ] 单文件、无外链依赖
- [ ] node --check 通过（提取 script 后）
- [ ] 状态 9 种齐全
- [ ] 打卡每个任务有独立备注框
- [ ] 岗位匹配能实时算分
- [ ] 导出/导入/重置可用
- [ ] 页面无跨行字符串语法错误

### 第五步：交付
- 给出完整 HTML 文件，命名 `秋招工作台.html`
- 附 30 字使用说明：双击打开 → 添加单位 → 勾选打卡 → 定期「💾 保存数据」备份

## 注意事项
- 公司数据初始为空（用户自己录），**不要**塞入示例公司（除非用户要求）
- 时间线/打卡/岗位匹配内容按用户岗位行业定制，不要写死嵌入式（除非用户就是嵌入式）
- 若用户已有旧工作台数据（localStorage 或 JSON 备份），提醒可导入迁移
- 生成前先确认用户信息完整，缺失的字段用合理默认值并告知用户
